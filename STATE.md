## Operating rules

- Never label an unfinished integration as working, or mark a mission complete from model self-report alone.
- The native runtime must remain usable without AIOS. AIOS is only a future optional external provider.
- Preserve the public repository's dependency boundaries; no new database, broker, browser daemon or self-hosted model runtime without measured justification.
- User credentials and local mission data are never source-controlled. The smoke tests in this repository are synthetic.
